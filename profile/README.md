# openfabriq

**The Terraform of software factories.** AI agents that triage, implement, review and fix your GitHub repository, described in readable files and run on your own machine.

- You describe the factory in an `openfabriq/` folder of your repository: who works, when, and what they may write.
- `openfabriq plan` shows what will change, security first; `openfabriq apply` applies it.
- Agents propose; the engine writes to GitHub only what you allowed; a person merges.

The engine's repository opens soon.
